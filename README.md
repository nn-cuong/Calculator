# Calculator App

Một ứng dụng máy tính khoa học (Scientific Calculator) mã nguồn mở, được thiết kế và tối ưu hóa đặc biệt cho thiết bị **TrimUI Brick Pro** (màn hình IPS 1024×768, vi xử lý Allwinner A133p, TrimUI OS).

---

## 🌟 Tính năng nổi bật

- **Chế độ kép tiện lợi:**
  - **Tab 123 (Cơ bản):** Đầy đủ các phép toán số học thông dụng ($+$, $-$, $\times$, $\div$), phần trăm ($\%$) và cụm dấu ngoặc đơn (`(`, `)`).
  - **Tab Fx (Khoa học):** Hỗ trợ lượng giác (`sin`, `cos`, `tan`), lượng giác ngược (`asin`, `acos`, `atan`), hàm logarit (`log`, `ln`), lũy thừa (`x²`, `e^x`, `10^x`), căn bậc hai ($\sqrt{x}$), giai thừa (`x!`), chế độ nghịch đảo (`Inv`) và chuyển đổi góc **DEG / RAD**.
- **4 Bộ chủ đề màu sắc Retro Scientific:**
  1. **Vintage Nature** *(Mặc định)* — Tông vàng cát hoài cổ, phím xanh rêu oliu dịu mắt và phím bằng đỏ gạch.
  2. **Midnight** — Xanh navy than chì hiện đại, độ tương phản cao, tối ưu khi dùng ban đêm.
  3. **Warm Paper** — Màu giấy kem ngà cổ điển, đem lại cảm giác tự nhiên như sách giấy.
  4. **Forest** — Sắc xanh rêu rừng thảo mộc sâu lắng, tĩnh lặng và thanh lịch.

## 🎮 Bảng nút điều khiển (Controller Mapping)

| Nút vật lý trên TrimUI | Thao tác tương ứng trong Calculator |
| :--- | :--- |
| **D-pad / Analog Joystick** | Di chuyển con trỏ trên bàn phím ảo (giữ đè để lướt nhanh) |
| **Nút A** | Nhập ký tự / chọn chức năng tại ô con trỏ đang đứng |
| **Nút B** | Xóa ký tự liền trước (Backspace / Delete) |
| **Nút X** | Phím tắt tính kết quả tức thì (`=`) |
| **Nút Y** | Phím tắt xóa sạch toàn bộ biểu thức (`AC`) |
| **Nút vai L1 / R1** | Chuyển đổi qua lại giữa Tab **123** và Tab **Fx** |
| **Cò vai L2 / R2** | Đổi chủ đề màu sắc (Vintage Nature $\leftrightarrow$ Midnight $\leftrightarrow$ Warm Paper $\leftrightarrow$ Forest) |
| **Nút SELECT** | Bật / Tắt bảng xem lịch sử phép tính (History Tape) |
| **Nút START** | Mở hộp thoại xác nhận thoát ứng dụng (A: Thoát, B: Hủy) |

## ⚙️ Hướng dẫn cài đặt

Để cài đặt ứng dụng lên máy TrimUI của bạn, chỉ cần làm theo các bước đơn giản sau:

1. Bấm vào nút `<> Code` màu xanh lá ở trên Github, sau đó chọn **Download ZIP** để tải mã nguồn về máy tính.
2. Giải nén file ZIP vừa tải ra, đảm bảo thư mục giải nén được đặt tên là `Calculator`.
3. **Copy toàn bộ thư mục `Calculator` đó và dán vào thư mục `Apps` nằm trên thẻ nhớ (SD Card) của máy.**
4. Lắp thẻ nhớ vào máy TrimUI, ứng dụng sẽ tự động xuất hiện trong giao diện menu Apps.
