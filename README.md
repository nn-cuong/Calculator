# Calculator App

Một ứng dụng máy tính (Calculator) mã nguồn mở, được thiết kế và tối ưu đặc biệt cho các hệ máy chơi game cầm tay (như Trimui Brick Pro, TrimUI Smart Pro).

## 🌟 Tính năng chính
- Hỗ trợ các phép toán cơ bản (Cộng, trừ, nhân, chia) và ngoặc.
- Chế độ máy tính khoa học (Functions: sin, cos, tan, log, ln, căn bậc 2, giai thừa...).
- Hỗ trợ chuyển đổi giữa Độ (Degrees) và Radian.
- Lưu trữ lịch sử phép tính (History).
- Giao diện hoài cổ (Vintage Nature Palette) trực quan, hỗ trợ điều khiển bằng gamepad/joystick.
